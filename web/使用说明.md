# DeepSeek 手机端对话应用（个人自用版）

> 基于 DeepSeek 官方开源仓库 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo)（MIT License，见 `LICENSE`）组装，接入 DeepSeek 官方 API（`https://api.deepseek.com`，模型 `deepseek-flash`）。
> 仅供本人使用，不对外提供服务、不用于售卖。

## 快速开始

```sh
pnpm install
pnpm dev
```

打开 http://localhost:8090，首次使用在「设置 → 数据管理」里填入 DeepSeek API Key（`sk-` 开头），点「确定」校验后即可对话。Key 只存在浏览器 localStorage，不会上传到除 `api.deepseek.com` 以外的任何地方。

生成静态包（可离线部署 / 直接打开）：

```sh
pnpm build
```

产物在 `dist/`，可用任意静态服务器托管，也可直接双击 `dist/index.html` 打开（浏览器需允许 `file://` 页面的存储与跨域请求）。

## 导入官方 App 的历史对话

支持直接导入 DeepSeek 官方 App / 网页端导出的历史对话：

1. 官方 App：设置 → 数据管理 → **导出所有历史对话**（生成 `deepseek_data-日期.zip`）。
2. 本应用：设置 → 数据管理 → **导入历史对话** → 选择该 ZIP → 确认导入（会覆盖本应用现有全部会话）。
3. 已验证：使用真实官方导出包（242 个会话、621 张图片、102 MB）导入成功，会话、思考过程、搜索引用、图片附件与消息分支均正常还原。

注意：导入会覆盖本地全部会话与附件；导入后原对话中的「继续生成」不可用（与官方 demo 行为一致）。

## 安装到手机（PWA）

1. 电脑与本机同一 Wi-Fi，先运行 `pnpm dev`（或静态托管 `dist/`）。
2. 手机浏览器访问 `http://<电脑局域网IP>:8090`（开发服务器启动时会打印 Network 地址）。
3. Android Chrome：菜单 →「添加到主屏幕 / 安装应用」；iOS Safari：分享 →「添加到主屏幕」。
   已配置 `manifest.webmanifest`、主题色、图标（官方鲸鱼图标）与全屏 `standalone` 显示。

注意：**语音输入 / 朗读需要 HTTPS**（浏览器麦克风安全限制）。局域网 HTTP 下聊天、深度思考、联网搜索、文件上传都可用，仅语音不可用；如需语音，可把 `dist/` 部署到任意 HTTPS 静态托管（如 Cloudflare Pages / Vercel / GitHub Pages）。

## 安卓 APK

已提供原生 WebView 壳工程（仓库中的 `android/` 目录）：把本项目的 `dist/` 打进 APK，包名 `com.deepseekclone.app`，安装后即为可全屏使用的独立应用（语音输入自动申请麦克风权限、拍照/相册/文件调用系统选择器、导出文件保存到「下载」目录）。构建与安装步骤见该目录的 README。

安卓返回键为应用内逐级返回：先关闭弹窗/下拉，再退出设置子页到设置根页，再关闭设置、抽屉、附件面板与搜索结果面板；在会话页返回首页；已在首页时才退出应用。

## 与官方 API 的一致性

请求完全走官方全家桶应用 API（2026-11-13 发布）的 Messages 协议：

- `POST https://api.deepseek.com/anthropic/v1/messages`（流式 SSE）
- 模型 `deepseek-flash`（DeepSeek-V4.1-Flash-1017），深度思考通过 `thinking: {type: enabled/disabled}`
- 服务端工具：`deepseek_web_search`（含深度思考搜索）、`deepseek_read_url`（阅读链接），引用以 `citations` 展示
- 文件：`/anthropic/v1/files` 上传，图片 64 MiB、文档 100 MiB，支持 PDF/Word/PPT/图片等
- 官方用户元信息标记 `latest_reminder`（日期、星期、位置、平台、语言）
- 会话标题 `title: {enabled: true}` 自动生成
- 语音输入 / 朗读：`/v1/tools/asr`、`/v1/tools/tts`（音色 stella 海星 / tide 暗潮）
- 系统提示词与官方一致：`该助手为DeepSeek，由深度求索公司创造。`

## 相对官方 demo 的本地修改

| 修改 | 说明 |
| --- | --- |
| 内容安全审核可开关，默认关闭 | 官方 demo 硬编码 `safety_check: {level: "high"}`。个人自用默认不开启；设置 → 通用设置 →「内容安全审核」可切回官方严格审核 |
| 应用标题 / 名称改为 DeepSeek | 页面标题、侧边栏、设置中显示 DeepSeek（原为「API 使用 demo」） |
| PWA 支持 | 新增 `manifest.webmanifest`、官方图标（`icon.svg`/`icon-192.png`/`icon-512.png`）、`viewport-fit=cover`、iOS 全屏 meta、顶部安全区适配 |
| Windows 构建修复 | `build` 脚本改用 `cross-env`，在 Windows 上可直接 `pnpm build` |
| 可选 API 地址覆盖 | 开发/构建支持环境变量 `DS_API_ORIGIN`（默认官方地址），便于本地联调 |

其余功能与官方 demo 完全一致：多会话与自动标题、编辑提问、重新生成、继续生成、消息分支、停止生成、Markdown（代码高亮 / KaTeX / Mermaid）、搜索引用与来源卡片、附件粘贴拖拽上传、语音输入与朗读、历史导入导出（兼容 DeepSeek 导出的 ZIP）、中英文、浅色/深色/跟随系统。

## 数据与隐私

- API Key、设置：浏览器 localStorage
- 会话与附件原件：浏览器 IndexedDB（按站点源隔离）
- 历史导入导出：ZIP；导入会覆盖本地全部会话
- 发送对话、上传附件、使用语音时，相应内容提交给 `api.deepseek.com`

## 常见问题

- **提示 API Key 无效**：确认 Key 属于 DeepSeek 开放平台，且账户有可用余额（https://platform.deepseek.com）。
- **端口被占用**：`pnpm dev` 默认 8090，可改 `rspack.config.ts` 里的 `devServer.port`。
- **手机打不开局域网地址**：确认防火墙放行、设备在同一网段；开发服务器启动日志里的 Network 地址即局域网访问地址。
- **语音按钮不可用**：非 HTTPS 页面浏览器禁止麦克风，见上文 PWA 部分。
- **余额与计费**：模型按 token 计费（峰谷价），语音按字符/时长计费，搜索/抓取服务端工具当前不单独计费；以官方价格页为准。
